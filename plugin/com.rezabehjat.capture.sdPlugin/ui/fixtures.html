Deck Control
Disarm the knobs after s without fixture activity (output keeps running; 0 = never)
Deck Control ON arms the knobs; OFF disarms them. The deck connects to Capture as a console when the plugin starts (it follows the selection; no DMX until a fixture knob or key is used, or a Wake) and stays connected: while OFF it keeps sending what Capture shows, and a change made in Capture (mouse, Control Pane) takes a channel back from the knob. Only quitting the Stream Deck app (or Capture closing the show) lets go. Any fixture knob or key arms it.
Changes made in Capture while the Stream Deck app wasn't running are overwritten by the deck's memory when the show opens.
