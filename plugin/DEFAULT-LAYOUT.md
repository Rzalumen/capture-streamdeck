# Default layout — generated, bundled, and offered on install (v0.4)

The plugin ships a Stream Deck+ profile named **Capture** (`com.rezabehjat.capture.sdPlugin/profiles/Capture.streamDeckProfile`,
declared in the manifest's `Profiles`). It is generated by `npm run gen-profile` from the command catalog, so it always
matches the actions in the plugin; nothing in it is configured by hand, and every key is a straight named command.
You can rearrange it freely in the Stream Deck app: Hold-to-fire and Dim-when-disabled are the only per-key options.

It switches in automatically whenever **Capture 2026** is the active application (`/Applications/Capture 2026.app`; for
another Capture build the profile with `CAPTURE_APP_PATH`, see the README).

## Rules

- **HOME** — row 0: View · Camera · Select · Edit; row 1: Patch & Focus · Windows · File · **Fixtures**. All eight are folders. (Look moved to the end of the View chain in v0.4.)
- **Child pages** — *Back* at the top-left key (`0,0`). Commands fill `1,0 → 3,0 → 0,1 → 3,1` (seven keys) in catalog order.
- **More ▸** — a folder with more than seven commands ends its page (bottom-right key) with a *More ▸* folder to the next
  page, which has its own *Back* (so *Back* steps back one page at a time).
- **Dials** — every page has its own four. HOME and every folder: Exposure · Ambient · Bloom · White Balance. The View
  pages: Contrast · Saturation · Fill · Hue Clamp. The Look folder: Flare · Flare Streaks · Flare Angle · Flare Size.
  The **Fixtures** folder has its own sets (below).
- **Every key shows its name as Stream Deck title text** (v0.5, `ShowTitle: true`), including folder, *Back* and *More ▸*. The plugin draws only the icon,
  dimming, flash text (“Stored”, “Hold”) and badges into the key image, and sets dynamic names (“Store 1”, position names) as the key's title.

## What is where

| Folder | Contents (catalog order) |
|---|---|
| View | the View category, then a **Look ▸** folder as the last item (Auto Exposure, Laser Flicker, Connection; Flare dials) |
| Camera | Swing/Focus commands (5 on the first page, 2 on the second) and a **Positions ▸** folder on the first page. *Positions ▸* is one page of its own: Camera Position 1–5, **Store Modifier** and a **Show ▸** folder (Show Position 1–8, Store Camera 1–5) |
| Select | the Select category |
| Edit | the Edit category (chains four pages) |
| Patch & Focus | the Patch & Focus category |
| Windows | **Tabs** (6) first, then the Navigate and Window categories |
| File | the File category |
| Fixtures | one page (v0.7.1): **Setup · Deck Control · Home Selected · Status · ◀ Page · Page ▶ · Next Fixture** (the Fixtures: keys; Release is no longer in the profile). Dials: **Attribute 1 · 2 · 3 · 4** (the Select dial left the page); the attribute pages (Main, then Colour · Beam · Shutters · Gobo/FX · Other in order, 4 channels on every page — built from the selected fixture's channels) are cycled with ◀ Page / Page ▶, not with profile pages |

Camera Position 1–5 and Store Modifier share one page (Camera › Positions ▸), so holding Store Modifier while pressing a
position works without changing page. Edit has four pages (25 commands, including the four *Edit › Model* items).

## Changing it

Edit the profile in the Stream Deck app (the plugin's actions are all in the **Capture** category, prefixed `View:`,
`Camera:`, …). To ship your own version, export it and run `npm run add-profile -- Capture.streamDeckProfile && npm run pack`;
`npm run gen-profile -- --force` goes back to the generated one.
